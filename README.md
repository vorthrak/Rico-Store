# Rico Store - Tampil Stylish dengan Fashion Terbaru

Rico Store adalah website e-commerce sederhana yang menawarkan berbagai produk fashion dengan desain yang menarik dan fungsional. Website ini dibuat dengan HTML, CSS, dan JavaScript untuk memberikan pengalaman belanja yang mudah dan menyenangkan. Setiap produk dapat dibeli langsung melalui WhatsApp, dengan tombol yang disediakan di halaman produk.

## Fitur
- **Mode Gelap dan Terang**: Toggle mode untuk kenyamanan pengguna di berbagai kondisi pencahayaan.
- **Koleksi Produk Fashion**: Daftar produk fashion terbaru dengan gambar dan harga.
- **Pembelian Via WhatsApp**: Pengguna dapat membeli produk langsung melalui WhatsApp.
- **Desain Responsif**: Website ini dioptimalkan untuk perangkat desktop dan mobile.

## Struktur Proyek

- `index.html`: Struktur halaman utama dan elemen-elemen dasar website.
- `style.css`: Gaya tampilan yang mencakup desain halaman dan mode gelap.
- `script.js`: JavaScript untuk interaktivitas, termasuk memuat produk dan fitur toggle mode gelap.
- `images/`: Folder untuk gambar produk (kaos, hoodie, celana, dll.).

## Instalasi

1. **Clone repositori ini**:
    ```bash
    git clone https://github.com/vorthrak/Rico-Store.git
    ```

2. **Masuk ke folder proyek**:
    ```bash
    cd Rico-Store
    ```

3. **Buka file `index.html`** di browser untuk melihat website.

## Cara Menggunakan

1. **Mode Gelap**: Klik ikon 🌙 di pojok kanan atas untuk mengaktifkan mode gelap.
2. **Pilih Produk**: Klik tombol "Beli via WhatsApp" di bawah gambar produk untuk melakukan pembelian langsung melalui WhatsApp.

## Teknologi yang Digunakan
- **HTML**: Untuk struktur halaman.
- **CSS**: Untuk styling dan desain responsif.
- **JavaScript**: Untuk interaktivitas (memuat produk, mode gelap).
- **WhatsApp API**: Untuk melakukan pembelian langsung via WhatsApp.
